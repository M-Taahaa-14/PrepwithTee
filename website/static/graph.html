See the shape of it.

Type a function the way the paper writes it and watch the curve. Roots and turning points are read off for you, so you can check a sketch you have already drawn by hand. Graphic display calculators are not allowed in these exams — this is for learning, not for the exam hall. Want to learn how to sketch these shapes by hand?
